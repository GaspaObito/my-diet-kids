# Guion corto para exponer

Buenos dias.

Mi proyecto se llama MyDiet Kids. Es una aplicacion movil hecha con Flutter para ayudar a ninos entre 6 y 12 anos a mejorar su alimentacion.

La idea principal es que aprender a comer saludable sea mas facil y divertido. Por eso la app tiene perfiles, alimentos, calculo de calorias, registro de agua, retos diarios, medallas y rachas.

Primero, el usuario crea un perfil con su nombre, edad, peso, estatura y nivel de actividad. Con esos datos la app calcula una meta aproximada de calorias y agua para el dia.

Despues, el usuario puede registrar que alimento comio y cuantos gramos. La app muestra las calorias, proteina, carbohidratos, grasa, fibra y azucar. Tambien dice si el alimento es saludable o si se debe consumir solo algunas veces.

La aplicacion tambien tiene retos diarios, como tomar agua, comer fruta, probar una verdura, cambiar gaseosa por agua y caminar 1500 pasos.

Cuando el usuario completa todos los retos del dia, la app lo felicita y le entrega una medalla. Si completa los retos varios dias seguidos, aumenta su racha, parecido a Duolingo.

Otra funcion importante es el reto de caminar. En un celular Android real, la app puede usar el sensor de pasos del telefono. Cuando detecta que el usuario llego a 1500 pasos, el reto se marca automaticamente.

Los datos se guardan dentro de la app, entonces si se cierra o se vuelve a abrir, el perfil, los alimentos, el agua, las medallas y las rachas siguen guardadas.

Con este proyecto aprendi a usar Flutter, organizar pantallas, guardar datos, crear modelos, manejar retos diarios y conectar Flutter con funciones nativas de Android.
