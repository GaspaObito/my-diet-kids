# MyDiet Kids - Resumen del proyecto

## Nombre del proyecto
MyDiet Kids

## Objetivo
Ayudar a ninos entre 6 y 12 anos a mejorar sus habitos de alimentacion mediante:

- Registro de perfiles.
- Calculo aproximado de calorias.
- Registro de alimentos.
- Recomendaciones saludables.
- Registro de agua.
- Retos diarios.
- Historial por dia.
- Medallas y rachas por cumplir los retos.
- Reto de caminar usando el sensor del celular Android.

## Problema que resuelve
Muchos ninos no saben si lo que comen todos los dias es saludable. Esta app ayuda a aprender de forma sencilla, como un juego, mostrando alimentos recomendados, metas diarias, retos y medallas.

## Como funciona
1. El usuario crea un perfil con nombre, edad, peso, estatura y actividad.
2. La app calcula una meta aproximada de calorias y agua.
3. El usuario registra alimentos y cantidad en gramos.
4. La app muestra si el alimento es saludable o si conviene consumirlo ocasionalmente.
5. El usuario registra agua consumida.
6. El usuario completa retos diarios.
7. Si completa todos los retos del dia, gana una medalla.
8. Si gana medallas varios dias seguidos, la app muestra una racha.

## Herramientas usadas
- Flutter: para crear la aplicacion movil.
- Dart: lenguaje principal del proyecto.
- Android SDK: para generar el APK.
- JDK 17: necesario para compilar Android.
- SharedPreferences: para guardar datos dentro de la app.
- Sensor Android TYPE_STEP_COUNTER: para contar pasos en celular Android.
